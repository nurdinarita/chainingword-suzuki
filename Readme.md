# ChainingWord SUZUKI

## Cara Install

1. Clone repository

```bash
git clone https://github.com/nurdinarita/chainingword-suzuki.git
```

2. Masuk ke folder project

```bash
cd chainingword-suzuki
```

3. Install dependency

```bash
npm install
```

4. Jalankan aplikasi

```bash
node app-default.js
```
